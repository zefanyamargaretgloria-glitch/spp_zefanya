# spp_zefanya
dibuat menggunakan PHP dan MySQL untuk membantu pengelolaan data pembayaran SPP sekolah. memiliki fitur login untuk admin, pengelolaan penambahan, penampilan, pengubahan, dan penghapusan data, pengelolaan data kelas yang mencakup nama kelas dan kompetensi keahlian. untuk mempermudah agar data tersimpan secara terstruktur dan lebih mudah dikelola.
